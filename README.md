# Hi, I'm Kaiya 👋

I build with AI, mostly because it's the most fun thing I know: multi-agent systems, local models, AI apps and games.

## What I'm building right now

- **An agent crew with an overseer.** Several AI coding agents from different providers (Claude, Codex, open models) work as one team: an overseer plans and checks the work, helpers build, two different models review every release, and a backup overseer on another provider can take over if the main one goes down.
- **A robot playtester for my Game Boy game.** A Go-Explore agent plays my original Game Boy Color game in an emulator and maps where it can and can't reach, to find dead ends and invisible walls before a person does.
- **Private, on-device AI.** Local models on my own laptop, including a diary companion that never leaves the house.
- **Desk robots.** Little ESP32 companions with their own voices, moods and chirps.

## How I like to work

- Tests I can trust: I plant bugs on purpose to check that the tests actually catch them.
- Privacy first: personal data stays local, and helpers only ever see code.
- Small, honest steps, and a lot of curiosity.
